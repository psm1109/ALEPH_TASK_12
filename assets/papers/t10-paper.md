# 성격 특성과 청취 음악의 음향·가사 특성의 관계

## 표지

**제목:** 성격 특성과 청취 음악의 음향·가사 특성의 관계: 공개 집계자료 330명의 상관분석과 개방성 예측 비교  
**작성자:** 박선민  
**작성일:** 2026년 10월 7일  
**연구 유형:** 공개 자료를 이용한 탐색적 이차자료 분석

## 초록

성격이 청취 음악의 음향·가사 특성과 관련되는지, 가사 추가가 개방성 예측을 개선하는지 알아보고자 했다.  
Sust 등(2023)이 공개한 개인별 집계자료 330명을 이용하여 세 가설을 검토했다.  
최초 분석은 피어슨 상관과 일반 선형회귀, 후속 탐색 분석은 순위·부분 상관과 Ridge 회귀를 사용했다.  
상관의 불확실성은 2,000회 부트스트랩으로, 예측 성능은 5분할 교차검증 10회의 평균절대오차로 평가했다.  
외향성–평균 valence의 피어슨 상관은 0.065518, 정서적 안정성–가사 긍정 정서의 상관은 −0.018804였다.  
최초·후속 상관의 95% 신뢰구간은 모두 0을 포함하여 예상한 양의 관계를 지지할 근거가 부족했다.  
가사 결합의 평균 ΔMAE는 일반 선형회귀 −0.014996, 작은 Ridge −0.006411, 확장 Ridge −0.005326이었다.  
이번 표본·분석 조건에서는 가사 결합에 따른 평균 예측 개선을 확인하지 못했으며 인과관계나 보편적 무관계를 뜻하지 않는다.

## 본문

### 1. 서론

음악을 선택하는 방식에는 개인의 심리적 특성이 반영될 수 있다. 음악 선호 차원과 성격의 관련성을 다룬 Rentfrow와 Gosling(2003), 음악 속성에 대한 선호를 살핀 Greenberg 등(2016)은 이러한 질문의 배경을 제공한다. 그러나 장르나 지각된 음악 속성에 대한 선호가 실제 청취 음악의 평균 음향 지표와 동일한 것은 아니다. 성격과 음악의 관계를 구체적으로 확인하려면 무엇을 선호의 지표로 삼는지 명확히 해야 한다.

Qiu 등(2019)은 좋아하는 노래 가사의 단어와 성격 사이의 관련성을 보고했다. Sust 등(2023)은 자연스러운 음악 청취 행동에서 얻은 음향·가사 특징을 성격 예측에 활용했다. 이러한 선행연구는 음악의 음향뿐 아니라 가사도 검토할 근거를 제공한다. 다만 좋아하는 노래의 가사에 관한 결과를 전체 청취 기록의 집계값에 그대로 적용하거나, 성격을 예측할 수 있다는 사실만으로 가사를 추가하면 항상 예측력이 높아진다고 판단할 수는 없다.

본 연구는 “개인의 성격 특성은 청취 음악의 음향·가사 특성과 어떤 관련이 있으며, 가사 정보를 추가하면 개방성 예측이 개선되는가?”를 묻는다. 음악 선호는 공개 자료에 제공된 개인별 청취 음악 특성으로 조작적으로 정의하고 다음 가설을 설정했다.

1. **H1:** 외향성 점수가 높을수록 청취 음악의 평균 음향적 긍정성(valence)이 높을 것이다.
2. **H2:** 정서적 안정성 점수가 높을수록 청취 음악 가사의 평균 긍정 정서 점수가 높을 것이다.
3. **H3:** 음향·가사 특성을 함께 사용하는 모형은 음향 특성만 사용하는 모형보다 개방성 예측의 평균절대오차(MAE)가 작을 것이다.

연구의 목적은 위 가설을 공개 자료에서 검토하고, 예상과 다른 결과도 전체 기록과 함께 보고하는 데 있다. 성격이나 청취 행동을 조작하지 않았으므로 인과관계를 검증하는 실험은 아니다. 연구 질문과 문헌 검토, 분석 설계, 결과 기록은 각각 1.md~4.md를 바탕으로 통합했다.

### 2. 방법

#### 2.1. 자료 출처와 분석 대상

Sust 등(2023)의 [OSF 공개 저장소](https://osf.io/x7dar/)에서 확보한 `PersonalityComputingWithMusic.zip` 버전 1과 온라인 부록을 사용했다. 원 연구는 2014~2018년에 수행되었으며, 이번 자료 수신 시각은 2026년 10월 6일 09시 52분 59초(한국 시간)다. 최초 분석은 10월 6일, 추가 자료 검토와 분석은 10월 6~7일에 수행되었다.

분석 단위는 개인이다. `data_des.csv`는 330행, 고유 참여자 ID 330개, 이름 있는 열 904개를 포함한다. 예측용 `data_ML.csv`도 같은 330명을 담고 있으며 이름 있는 열은 879개다. 두 파일의 공통 열 전체와 행 순서가 일치하는 것을 확인한 뒤 참여자를 연결했다. 두 파일을 합쳐 660명으로 계산하지 않았다. 각 가설에 필요한 수치가 유효한 참여자를 포함했고, 모든 분석에서 최종 표본은 330명, 중복 및 결측으로 제외된 인원은 0명이었다. 분석에 쓰지 않는 열의 결측 때문에 참여자를 제외하거나 가사 점수 결측을 0으로 채우지 않았다.

공개 자료는 저자가 처리한 **개인별 집계자료**다. 원래의 개별 청취 로그, 설문 문항별 응답, 가사 원문은 확보하지 못했다. 따라서 이번 분석에서 말하는 원자료는 분석 입력으로 사용한 공개 파일이며, 관찰 당시의 모든 기록을 뜻하지 않는다. 추가 검토한 `features_final.RDS`의 753명과 곡별 가사 파일의 30,135개 가사 ID는 성격 분석의 추가 참여자로 취급하지 않았다.

#### 2.2. 변수와 측정

| 개념 | 공개 자료의 열 | 분석에서의 의미 |
|---|---|---|
| 외향성 | `E` | BFSI 외향성 개인 모수 점수; H1의 성격 변수 |
| 정서적 안정성 | `ES` | BFSI 정서적 안정성 개인 모수 점수; H2의 성격 변수 |
| 개방성 | `O` | BFSI 개방성 개인 모수 점수; H3의 예측 대상 |
| 음향적 긍정성 | `mean_music_valence` | 청취 음악의 평균 valence; 0~1 지표 |
| 가사 긍정 정서 | `mean_nrc_pos` | NRC 감정 사전 기반 긍정 정서 지표의 개인별 평균 |
| 통제 변수 | `age`, `gender`, `studyDays`, `prop_lyrics` | 나이, 제공된 성별 코드, 관찰 일수, 가사 확보율 |

성격 점수는 1~4의 문항 응답 평균이 아니다. 관측 범위는 외향성 −2.1813~1.9633, 정서적 안정성 −2.1860~2.5201, 개방성 −1.9994~2.1176이었다. 음향적 긍정성은 0.157929~0.734429, 가사 긍정 정서 지표는 0.097839~0.278393이었다. 이 범위는 현재 표본의 최솟값·최댓값이며 척도의 이론적 범위가 아니다. 정서적 안정성은 신경성으로 역산하지 않았다.

저자 코드에서 개인별 음악 평균은 20초를 초과해 청취한 기록 중 해당 특성이 있는 값으로 계산된다. 반복 청취가 반영될 수 있으므로 서로 다른 곡만의 단순 평균으로 설명하지 않는다. 가사 정서 지표는 가사의 특성이며 청취자의 실제 감정이나 감상 후 기분을 측정한 값이 아니다. 참여자별 관찰 기간은 3~85일, 가사 확보율은 0.032258~1.000000이었다.

#### 2.3. 최초 분석

H1은 `E`와 `mean_music_valence`, H2는 `ES`와 `mean_nrc_pos` 사이의 피어슨 상관으로 검토했다. 가설별 2,000회 부트스트랩으로 330명을 복원추출하고 상관을 다시 계산했다. 난수 시드는 20261006이며 각 가설에서 난수 생성기를 새로 시작했다. 95% 신뢰구간은 부트스트랩 분포의 2.5·97.5 백분위수를 선형 보간하여 계산했다. 양측 p값을 보고하고 H1·H2 두 검정에 Holm 보정을 적용했다.

H3는 절편을 포함한 일반 선형회귀로 개방성을 예측했다. A 모형은 음향 평균 10개, B 모형은 같은 음향 평균 10개와 NRC 가사 정서 평균 10개를 사용했다. 음향 입력은 danceability, energy, loudness, mode, speechiness, acousticness, instrumentalness, liveness, valence, tempo의 개인별 평균이다. 가사 입력은 positive, negative, fear, anger, sadness, disgust, joy, trust, surprise, anticipation에 해당하는 평균 지표다. 실제 열 이름과 전체 목록은 분석 코드와 결과 JSON에 보관했다.

#### 2.4. 탐색적 후속 분석

최초 결과를 확인한 뒤 같은 표본에서 스피어먼 순위 상관과 부분 피어슨 상관을 추가했다. 부분 상관은 나이·성별·관찰 기간·가사 확보율로 두 가설 변수를 선형 보정한 잔차 사이의 상관이다. 방법별·가설별 2,000회 부트스트랩을 수행했으며, 부분 상관은 재추출할 때마다 보정을 다시 계산했다. Holm 보정은 각 방법의 H1·H2 두 검정에 적용했다. 모든 분석 방법을 합친 확증적 다중검정 보정은 아니다.

예측에서는 과적합을 억제하는 Ridge 회귀를 두 입력 구성에서 비교했다.

| 비교 | A: 음향 입력 | B: 동일 음향+가사 관련 입력 |
|---|---|---|
| 작은 Ridge | 음향 평균 10개 | 음향 평균 10개+NRC 정서 10개, 총 20개 |
| 확장 Ridge | 음향 평균 10개+음악 조성 비율 11개, 총 21개 | 음향 21개+가사 관련 813개, 총 834개 |

가사 관련 813개는 NRC 정서 10개, 주제 30개, BERT 표현 벡터 768개와 기타 5개다. 기타 지표는 노골적 표현 여부, 영어·독일어 곡 비율, 가사 길이, 가사 확보율이다. 따라서 확장 B의 비교는 가사 의미나 정서만의 효과를 분리하는 설계가 아니다. 전체 열 목록은 `data/results/card4_extended/protocol.json`에 있다. 별도로 각 학습 구간의 개방성 평균을 예측하는 기준모형을 평가했다.

후속 분석은 최초 결과를 본 뒤 정한 탐색적 분석이며 사전 등록이나 독립 표본의 확증 연구가 아니다. 자료 검토에서는 곡별 특징, 참여자 특성 RDS, 매칭 확인 파일, 저자 코드와 부록의 정의·결과를 확인했으나 저자의 전체 분석을 재현하지 않았다.

#### 2.5. 교차검증과 판단 기준

최초 선형회귀와 후속 모형은 모두 같은 참여자와 바깥 분할을 사용했다. 5분할 교차검증을 시드 101~110으로 10회 반복하여 각 구간에서 264명을 학습, 66명을 평가했다. 상수 열 제거와 표준화는 학습 자료에서만 결정했다. ID, 행 번호, 모든 성격 점수와 하위 척도를 입력에서 제외했고 `O`는 정답으로만 사용했다.

Ridge 규제 강도는 각 바깥 학습 구간 내부의 5분할에서 선택했다. 후보는 0.1, 1, 10, 100, 1000, 10000이며 내부 평가 MAE가 가장 작은 후보를 선택했다. 내부 시드는 바깥 시드×10+바깥 구간 번호였다. 내부 학습마다 전처리를 다시 계산하고, 선택 후 바깥 학습 자료 전체에 재학습하여 평가 자료를 예측했다. 바깥 평가 자료로 전처리나 규제 강도를 정하지 않았다.

MAE는 예측과 실제 개방성 점수 사이의 절대 차이 평균이다. 각 반복에서 330명에 대한 학습 외 예측을 모아 MAE를 계산하고 10회 평균과 표본 표준편차(SD)를 보고했다. **ΔMAE=MAE_A−MAE_B**로 정의하여 양수일 때 가사 결합이 개선된 것으로 해석했다. H1·H2의 지지 기준은 양의 상관, 신뢰구간 하한 > 0, Holm 보정 p < 0.05의 동시 충족이다. H3는 평균 ΔMAE와 반복별 차이를 함께 평가했다. 같은 표본의 반복값을 독립 표본으로 간주하는 t검정은 하지 않았다.

| 후속 작은 Ridge, 10/20 | 0.551646 ± 0.003462 | 0.558058 ± 0.005954 | −0.006411 ± 0.005834 | 1/10 |
| 후속 확장 Ridge, 21/834 | 0.554253 ± 0.006055 | 0.559579 ± 0.004716 | −0.005326 ± 0.004994 | 2/10 |
| 후속 학습 평균 기준모형 | 0.590312 ± 0.001285 | 해당 없음 | 해당 없음 | 해당 없음 |

MAE의 단위는 공개 BFSI 개방성 개인 모수 점수와 같다. 표의 SD는 같은 330명을 반복 분할했을 때의 변동이며 모집단 신뢰구간이 아니다. 문서 수치는 소수점 여섯 자리로 반올림했고, 전체 정밀도의 결과는 CSV·JSON으로 보관했다.

세 비교 모두 가사 결합 모형의 평균 오차가 음향 단독 모형보다 컸다. 작은 Ridge는 시드 104에서만, 확장 Ridge는 시드 101·105에서만 개선되었다. 구간별로 B가 개선된 경우도 있었지만 반복 전체 330명의 MAE를 판단 단위로 삼았으며 유리한 반복만 선택하지 않았다. 따라서 이번 비교는 H3를 뒷받침하지 못했다.

네 Ridge 모형의 평균 MAE는 학습 평균 기준모형보다 작았다. 그러나 이 특정 기준보다 작은 오차와 가사 추가의 이득은 별개의 결과다. 최초 결과는 `data/results/card4/`, 후속 결과는 `data/results/card4_extended/`에 보관했다. 최초 분석은 가설별 부트스트랩 2,000개, 모형·구간 기록 100행, 예측 기록 3,300행을 포함한다. 후속 분석은 부트스트랩 8,000행, 모형·구간 기록 250행, 규제 후보 평가 1,200행, 예측 기록 3,300행을 포함한다. 예측 3,300행은 새 참여자 3,300명이 아니라 같은 330명에 대한 10회 기록이다.

### 4. 논의

#### 4.1. 가설과 선행연구에 대한 해석

이번 자료에서는 외향성과 평균 음향적 긍정성, 정서적 안정성과 가사 긍정 정서의 뚜렷한 양의 관계를 확인하지 못했다. 최초와 후속 상관의 점추정치는 작았으며 모든 구간이 0을 포함했다. 이는 관계가 정확히 없다는 증명이 아니라 이번 자료와 측정 방식에서 예상한 방향을 뒷받침할 근거가 충분하지 않았다는 뜻이다.

가사 추가의 평균 예측 이득도 확인되지 않았다. 일반 선형회귀뿐 아니라 Ridge와 확장 입력을 사용한 비교에서도 평균 ΔMAE가 음수였다. 가사 표현 범위를 넓히거나 규제를 적용하는 것만으로 이번 표본의 평균 개선을 얻지는 못했다. 다만 이 결과를 모든 가사 표현·예측 모형·모집단에서 가사가 무용하다는 주장으로 확대할 수 없다.

선행연구와 이번 분석은 측정과 비교 조건이 다르다. Qiu 등(2019)의 좋아하는 노래와 본 연구의 실제 청취 집계는 동일한 선호 지표가 아니다. Greenberg 등(2016)의 지각된 음악 속성과 평균 음향 valence도 구분해야 한다. Sust 등(2023)은 Elastic Net·랜덤포리스트 등 다른 모형과 평가 조건을 사용했다. 따라서 이번 결과는 저자 연구 전체를 재현하거나 반박하는 결과가 아니라, 해당 공개 자료에 설정한 세 가설과 분석 조건에 관한 결과다.

#### 4.2. 예상과 다른 결과의 가능한 설명

개인별 평균은 청취 상황에 따른 차이를 줄였을 수 있으며, 실제 청취가 의도적인 선호와 항상 일치하지 않을 수도 있다. 가사 사전 점수 또한 사람이 이해하는 의미나 정서를 완전히 표현하지 못할 수 있다. 관찰 기간과 가사 확보율의 차이는 부분 상관에서 보정했으나, 원래 로그가 없어 기간을 통일하거나 누락 곡의 편향을 직접 재계산하지 못했다.

예측에서는 확장 B의 834개 입력이 바깥 학습 인원 264명보다 많고, 가사 표현들 사이에 정보 중복이 있을 수 있다. Ridge를 적용했지만 표본 규모, 규제 후보 범위, 비선형 관계, 학습 손실과 MAE 평가의 차이가 결과에 미치는 영향을 따로 분리하지 않았다. 이 설명들은 가능한 후속 연구 방향이며, 이번 오차 증가의 원인으로 입증된 것은 아니다.

#### 4.3. 한계와 후속 연구

첫째, 관찰 집계자료이므로 성격이 음악 선택을 일으킨다거나 음악이 성격을 바꾼다고 말할 수 없다. 네 변수를 보정한 부분 상관도 인과 효과가 아니다. 둘째, 공개 집계값은 저자의 전처리와 필터를 거친 값이며 원래 로그·문항 응답·가사 원문에서 모든 지표와 참여자 선정을 다시 구성할 수 없다. 매칭 검토 파일의 잘못된 매칭 건수를 최종 자료의 오류율로 해석할 수도 없다.

셋째, 후속 분석은 최초 결과를 확인한 뒤 정했고 같은 330명을 사용했다. 중첩 교차검증은 평가 자료를 학습과 규제 선택에서 제외했지만 다른 모집단의 외부 검증을 대신하지 않는다. 넷째, 확장 가사 묶음에는 언어·길이·확보율도 포함되어 있어 가사 의미나 정서만의 효과를 분리하지 못했다. 다섯째, 학습 평균 기준모형보다 작은 MAE만으로 실용적인 성격 판별이나 모든 기준모형에 대한 우월성을 주장할 수 없다. MAE에서는 중앙값을 사용하는 상수 기준도 비교할 필요가 있다. 한국인 전체나 모든 음악 청취자에게 일반화하지 않는다.

후속 연구에서는 가사 표현·모형·표본 조건에 따라 예측 이득이 달라지는지를 사전에 정의하고 독립 자료에서 평가할 필요가 있다. H1·H2는 결과에 맞추어 방향을 뒤집지 않고 유지한다. H3의 조건별 이득은 앞으로 검토할 질문이며 이미 확인된 결과가 아니다. AI는 질문·문헌·설계의 정리와 분석·문서 작성 보조에 활용했으며, 연구 판단은 보관된 공개 입력과 계산 결과에 근거했다.

#### 4.4. 결론

공개된 330명의 성격·음악 집계자료에서 예상한 두 양의 상관을 지지할 충분한 근거를 얻지 못했고, 음향에 가사 정보를 결합한 세 예측 비교에서도 평균 MAE 개선을 확인하지 못했다. 이 결론의 범위는 이번 표본·변수·분석 조건이며, 정확한 무관계나 가사 정보의 보편적 무용성을 증명하지 않는다. 예상과 다른 결과도 원자료, 전체 결과와 재현 절차를 함께 보존했다.

## 재현 방법

ZIP을 풀고 `t10_paper` 폴더에서 실행한다. 8MB 제출 한도에 맞춰 분석에 직접 입력한 **두 CSV**, 최초·후속 분석 및 검증 코드, 계산 결과, 실행에 필요한 변수 목록·해시·출처 기록을 포함했다. 두 CSV는 `data/raw/personality_music/extracted/data/final data/`에 있으며 공개 파일을 변경하지 않은 추출본이다. 같은 자료를 다시 내려받지 않고 상관·예측 계산을 재실행할 수 있다.

대형 원본 ZIP, RDS, 곡별 특징·매칭 파일, 부록과 저자 코드 등 자료 구조 검토용 파일은 제출 ZIP에서 제외했다. 그 검토의 기록인 `source_review.json`은 후속 분석이 변수 목록과 입력 해시를 읽는 데 필요하여 포함했다. 자료 구조 검토 자체를 다시 수행하려면 [OSF 저장소](https://osf.io/x7dar/)의 [원본 ZIP](https://osf.io/download/kxjhg/)과 부록, 원래 검토 코드를 별도로 확보해야 한다. 아래 절차는 포함된 두 CSV에서부터의 계산 재현이며, 제외한 자료의 구조 검토까지 재실행하는 절차는 아니다.

먼저 Python 표준 라이브러리만으로 입력과 보관된 결과를 확인한다.

```text
python reproduction/verify_package.py
python data/verify_card3_design.py
python data/verify_card4_results.py
python data/verify_card4_extended_results.py
```

전체 계산을 다시 하려면 Python 3.12.14의 별도 환경에서 고정 버전을 설치한 뒤 다음 순서로 실행한다. 결과를 다시 쓰므로 배포본을 보존하려면 ZIP을 다른 폴더에 풀어 실행한다.

```text
python -m venv .venv
```

Windows에서는 `.venv\Scripts\activate`, macOS·Linux에서는 `source .venv/bin/activate`로 환경을 활성화한 뒤 실행한다.

```text
python -m pip install -r data/requirements-card4.txt
python data/verify_card3_design.py
python data/analyze_card4.py
python data/analyze_card4_extended.py
python data/verify_card4_results.py
python data/verify_card4_extended_results.py
```

기록된 주요 버전은 NumPy 2.3.5, pandas 3.0.1, SciPy 1.18.1, scikit-learn 1.9.1, pyreadr 0.5.7이다. CSV는 UTF-8, 세미콜론 구분자, 쉼표 소수점 형식이며 pandas에서는 `read_csv(path, sep=";", decimal=",", index_col=0)`로 읽는다. 최초·후속 결과는 각각 `data/results/card4/`, `data/results/card4_extended/`에 생성된다. 부트스트랩 시드는 20261006, 바깥 교차검증 시드는 101~110이다.

`reproduction/README.md`에는 폴더 구성과 실행 안내, `reproduction/manifest.json`에는 배포 파일별 SHA-256이 있다. 검증의 PASS는 파일과 계산 기록의 일치를 뜻하며 가설 지지를 뜻하지 않는다. 이 절차는 공개 집계자료부터의 분석을 재현하며, 비공개 청취 로그에서 집계값을 생성하는 원 연구 전체를 재현하지 않는다.
