# 흑백 포트폴리오 사이트

승인한 흑백 시안을 구현한 정적 사이트입니다. 별도의 설치나 회원 가입이 필요하지 않습니다. 이름, 경험, 실제 기록, 논문과 문서가 제공되지 않아 해당 부분은 빈칸으로 남겼습니다. 이미지 속 예시 이름은 사용하지 않았습니다.

## 확인하기

`index.html`을 브라우저로 열면 됩니다. 또는 이 폴더에서 아래 명령으로 열고 `http://localhost:8000`에 접속하세요.

```sh
python -m http.server 8000 --bind 127.0.0.1
```

첫 화면의 버튼과 상단 메뉴는 해당 구역으로 이동합니다. 모바일에서는 대표작과 문서 카드가 세로로 배치됩니다. 자료가 없는 항목은 링크 대신 준비 중으로 표시합니다.

## 내 내용 입력하기

- `content.js`: 이름, 직접 작성한 한 줄 소개, 이야기 3개 장면, 논문, 문서, 연락 수단을 입력합니다.
- 장면의 `date`에는 실제 날짜를 `YYYY-MM-DD`로 입력합니다. 소설의 각색된 부분은 사실로 되돌린 뒤 넣으세요.
- `paper.url`과 문서 `url`에는 공개 주소 또는 `documents/resume.pdf` 같은 상대 경로를 넣습니다. 상대 경로에 해당하는 실제 파일도 함께 넣어야 합니다.
- `contact`에는 공개하기로 정한 수단 하나만 넣습니다. 이메일이면 `url`을 `mailto:내주소`로 지정합니다.
- 다른 사람의 실명과 비밀값은 입력하지 마세요. 실제 자료가 연결되기 전에는 지원용 완성본이 아닙니다.

## 기록을 갱신하는 장치

Python 3.10 이상, 외부 라이브러리나 API 키 없이 실행됩니다. `data/records.json`에 실제 기록을 추가하고 실행하세요.

```sh
python scripts/update_records.py
```

입력 형식 예시입니다. 아래 숫자는 설명용이며 사이트에 반영되어 있지 않습니다.

```json
{"records":[{"date":"2026-01-05","planned":4,"completed":3,"restarts":1,"source":"1주차 기록, 2쪽"}]}
```

날짜당 한 기록을 허용합니다. 주간 기록이면 매주 동일한 기준 날짜를 사용하세요. `planned`는 계획한 과제 수, `completed`는 완료한 과제 수, `restarts`는 중단 후 다시 시작한 행동 횟수입니다. 출처에는 공개할 수 있는 문서명·날짜·쪽수를 남기세요.

기록 기간은 기록이 존재하는 ISO 주의 개수입니다. 빈 주는 포함하지 않습니다. 과제 지속률은 `완료 건수 / 계획 건수 × 100`입니다. 계획이 0건이면 계산하지 않습니다. 다시 시작한 횟수는 행동 지표이며 심리검사 점수가 아닙니다. 13주가 채워지기 전에는 실제 입력한 주 수만 표시합니다.

결과는 `records-result.json`, 사이트가 읽는 `records-result.js`, 검토용 `paragraph-candidates.md`입니다. 문단 후보는 사실 기반 초안이며 본문에 자동 적용하지 않습니다. 검토한 문장만 `content.js`에 반영하세요. 입력이 잘못되면 기존 결과를 보존한 채 오류로 종료합니다.

같은 입력을 새 폴더 두 곳에서 실행하여 세 결과 파일의 내용을 비교할 수 있습니다.

```sh
python scripts/update_records.py --output .checks/first
python scripts/update_records.py --output .checks/second
```

## 공개하기

이 폴더의 `index.html`, `styles.css`, `app.js`, `content.js`, `records-result.js`, `assets`와 직접 등록한 문서 파일을 정적 웹 호스팅에 올리면 됩니다. 사이트는 방문자 통계, 댓글, 로그인, 외부 API 호출을 사용하지 않습니다. 이번 작업에서는 전체 소스 작성과 로컬 확인까지만 진행합니다.

## AI와 나의 판단

- AI: 승인한 흑백 디자인을 반응형 페이지와 기록 집계 도구로 구현했습니다.
- 나: 공개할 이름과 연락 수단, 실제 장면·날짜·출처를 확인한 뒤 입력합니다.
- 함께: 숫자와 문단 후보를 검토하고 사실과 일치하는 내용만 공개합니다.
